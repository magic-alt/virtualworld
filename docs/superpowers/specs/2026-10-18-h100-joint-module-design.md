# H-100 谐波关节模组与体验控件设计

日期：2026-10-18

分支：`feat/h100-joint-module`

基线：已合并 PR #3 的 `main`（`5517056`）

## 1. 目标和范围

将 `/?project=demo-harmonic-joint` 从大型简化教学件升级为结构可信、可分层观察的紧凑型 AI 3D 关节展示。保留 H-100 名称、项目 ID 和 100:1 演示传动比。用户明确要求包含谐波减速器、无框力矩电机、驱动板，以及可选永磁掉电抱闸。

优化模型、材质、装配展示、运动和该页面全部可见控件；网页与独立导出播放器使用相同机构运行逻辑和控制面板。保留现有 AI 提案、导出与高级编辑入口，主体验围绕观察和理解机构展开。

模型定位为有官方资料依据的原创结构演示。尺寸、绕组、PCB 布局和抱闸均不构成制造图、电路设计、额定扭矩、热性能或安全制动证明。不会将 AI 生成参数标记为人工确认。

## 2. 已确认的方向与方案取舍

采用“官方尺寸与结构依据 + 自绘内部总成”。不沿用原有底座直径 215 mm、壳体直径 180 mm、总高 165 mm 的大型教学外形；也不宣称复刻某一完整商业产品。

直接展示厂商外形 STEP 无法满足内部剖解要求；完全复刻商业模组还缺少内部装配图与授权依据。选定方案同时保留来源可追溯性、内部可观察性和可再生成性。

## 4. 模型结构与几何约束

### 4.1 尺寸与坐标

H-100 自绘基准采用底部安装法兰直径 110 mm、壳体外径 100 mm、总高 110 mm、中空通孔 18 mm。它们是本项目的演示封装尺寸，不是任何厂商产品尺寸。以米存储，Y 轴为关节轴，底面 Y=0，角度使用弧度。

轴向空间划分为：后端驱动与接口区、可选抱闸区、无框电机区、谐波传动区、输出轴承与法兰区。各区在 recipe 中明确起止与连接关系；不能把旧模型整体缩放后声称完成结构重建。径向尺寸、轴向配合和间隙由统一配方派生，并在实际导出几何上检查。

### 4.2 必须可识别的部件

| 子系统     | 展示内容                                                                 | 运动归属                                           |
| ---------- | ------------------------------------------------------------------------ | -------------------------------------------------- |
| 壳体与安装 | 安装法兰、圆筒壳、端盖、定位台阶、紧固件与密封示意                       | 固定                                               |
| 无框电机   | 定子叠片、齿、绝缘骨架、铜绕组、转子背铁、交替磁极、中空转轴及支撑轴承   | 定子固定；转子与输入轴同转                         |
| 谐波减速器 | 202 齿固定刚轮、200 齿薄壁柔轮、椭圆波发生器、薄壁柔性轴承、柔轮输出连接 | 刚轮固定；波发生器随输入；柔轮随输出并发生弹性形变 |
| 输出支承   | 交叉滚子轴承内外圈、交替滚子、压环、输出法兰及角度标记                   | 外圈固定；输出侧内圈与法兰同转                     |
| 驱动板     | 环形 PCB、功率级、母线电容、控制区、电源与通信连接器、三相出线示意       | 固定；电路仅为结构示意                             |
| 双编码器   | 输入与输出各自的读头／板、码环、安装支撑和感应间隙                       | 读头固定；相应码环随输入或输出                     |
| 可选抱闸   | 固定磁轭、永磁体、释放线圈、摩擦面、衔铁与输入轴连接                     | 固定部分与输入连接部分分别归组                     |

所有扭矩传递连接应连续：转子 → 输入轴 → 波发生器 → 柔轮 → 输出法兰。刚轮、定子与驱动板应有可见固定支撑。中央贯通路径在装配态保持真实开放；不能只在外壳画孔、内部用实心轴封堵。

齿形、波发生器接触和柔轮变形属于原理模拟，不求解齿面接触应力。维护显式允许接触清单，并区分安装接触、预期啮合与不允许的穿插；不能用宽泛的总成白名单掩盖冲突。

### 4.3 材质与展示

采用克制的工业产品展示：金属粗糙度区分外壳、加工面、轴承与叠片；铜绕组、磁极、绿色 PCB 与接口具备可辨识颜色。细节通过几何和材质表达，文字说明放在面板中，避免在模型上堆叠遮挡标签。

为阻挡观察的壳体和内部环状零件生成有封口的剖视替代件，保持装配态闭合。爆炸展开按功能层级和轴向装配次序分离，不能让所有固定件共用一条重叠位移。变化后按当前可见边界适配镜头，预留顶部栏和底部面板的安全空间。

## 5. SceneSpec 与运行时边界

保留现有 `mechanism.kind = harmonic` 及稳定运动组 ID。新增可选的展示元数据：子系统 ID、中文名称、说明、成员节点、默认可见性、可选部件归属和资料说明。字段通过严格 schema 验证，并检查引用、重复成员和运动组一致性；没有新字段的旧世界继续可加载。

默认结构、节点、尺寸和来源描述由 `assembleWorld` 的世界输入生成并最终进入 SceneSpec；引擎不得硬编码 H-100 节点名或尺寸。最终 GLB 序列化完成后读取真实节点路径，禁止按 Blender 临时对象顺序猜测 `assetNode`。

运行时保存播放、角度、转速、剖视、爆炸、观察选择与抱闸演示等瞬态状态，不把播放过程写回 SceneSpec。AI 或高级编辑对模型的持久修改仍通过现有已验证、原子的 SceneCommands；关闭项目或导出前不得把瞬态隐藏／旋转误当成场景编辑。

运行时提供可订阅的机构状态和明确的操作 API，控制面板从状态读取值，不另外维护一份 moving 标记。新增 API 只依赖公开 workspace 包，避免从运行时反向导入网页或生成器。订阅、事件、定时更新、克隆材质及 GPU 资源随项目切换和销毁释放。

## 6. 运动与可选抱闸行为

- 刚轮固定、柔轮 200 齿、刚轮 202 齿；输出角度为输入角度的 -1/100。双波变形随波发生器相对于柔轮的相位更新，固定件不随运动漂移。
- 初次进入为停止状态、输入角度 0、指令转速 6 RPM。播放与暂停保持当前相位；独立“运动归零”才归零，并保持停止。允许输入转速 -30 至 +30 RPM，滑条与数字输入联动，拒绝非有限数，反向保留当前角度。
- 暂停时可按输入轴 ±15° 步进；播放时步进按钮禁用。状态同时显示输入／输出角度、指令转速、实际演示转速和 100:1 反向传动关系。
- 全局暂停、设置弹层、页面隐藏等既有暂停来源继续有效。只有机构已播放、全局未暂停且抱闸未抱紧时，实际转速才非零；关闭设置后不能错误启动原本停止的机构。
- “安装可选抱闸”仅控制本次观察的选配状态与可见零件，不形成永久配置修改。默认安装、通电释放；可切换为“未安装”。
- 对已安装抱闸切换“抱闸线圈掉电”时，保持当前角度并阻止运动；显示“掉电抱紧”。恢复线圈供电后保持暂停，需主动播放。切换安装选项也保持当前角度并暂停。未安装时显示“无抱闸”，禁用线圈供电控件，不允许显示已制动。此控件演示独立抱闸释放回路，不模拟整机母线掉电后的滑行。
- 抱闸演示采用理想瞬时保持，不计算制动距离、惯量、热量或电磁回路；界面说明这一边界，不给出安全制动性能结论。

## 7. 共用控件与全部页面入口

在 `apps/web/shared/` 提取独立的机构控制组件，与已有 experience controls 共用运行时状态；React 页面负责挂载和销毁，静态播放器使用同一组件。通用世界的移动／故事控制不受影响。

| 控件／入口                  | 目标行为与验证                                                                                                             |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 播放、暂停、归零、步进、RPM | 行为遵守第 6 节，所有数值与模型状态同步；点击与键盘均可使用                                                                |
| 爆炸展开                    | 展开量可读，滑条受控、可恢复装配，展开后自动适配可见模型                                                                   |
| 剖视                        | 全壳／剖壳切换互斥；与爆炸、部件隐藏组合时无重复壳体与残留显示                                                             |
| 子系统观察                  | 按电机、减速器、驱动、编码器、抱闸、壳体和输出支承列出说明；支持显示切换、单独观察、恢复全部；不出现编辑变换手柄           |
| 视角                        | 默认、正视、侧视、顶视、适配当前模型；按实际可见边界和可用画面计算距离                                                     |
| 恢复展示                    | 恢复默认视角、装配、全壳、子系统可见性、选配与电源状态，停止并归零，指令转速恢复 6 RPM；不覆盖用户保存的画质偏好或项目内容 |
| 全局暂停                    | 标签和运行状态准确，暂停前后的机构相位保持                                                                                 |
| 全屏                        | 进入／退出状态同步，处理不支持或拒绝的结果，避免界面错误宣称已全屏                                                         |
| 播放设置                    | 画质实际作用到渲染器；菜单、Esc、焦点与暂停恢复一致；浏览器存储被禁用时仍可使用                                            |
| 返回首页                    | 正常返回；存在持久编辑时沿用未保存提示，不因瞬态观察误报修改                                                               |
| AI 改变世界                 | 保留提案预览、应用、撤销、保存及项目代际隔离；不得把抱闸示意视为安全参数确认                                               |
| 导出世界                    | 下载包含当前持久 SceneSpec 与本地资产的可独立运行包；不依赖编辑服务或外部网络；首次打开为确定的默认播放状态                |
| 高级编辑                    | 正确打开当前项目，展示与编辑边界明确，返回主体验后不残留旧运行时                                                           |

静态播放器不提供依赖编辑服务的 AI 或项目保存入口，机构面板与全局播放设置保持功能一致。控件采用明确中文标签、可访问名称、可见焦点及足够点击区域。移动端面板可收起／滚动，不挤出横向页面，不盖住返回和全局暂停，不要求悬停才能操作。

## 8. 验证与交付标准

### 模型与离线产物

1. 实际运行固定 Blender 构建，保留可再生成源码和配方；运行 finalize、GLTF validator 与世界装配验证，保留警告，错误必须清零。
2. 从最终 GLB 测量单位、总尺寸、通孔、层级、材质和 morph；核对部件与运动归属、双编码器、驱动板和可选抱闸确实存在。矩阵、引用和最终节点路径有效。
3. 检查装配态、剖视态、爆炸态及多个输入相位：明确检测非预期穿插与接触白名单，不能只检查包围盒或导入成功。视觉核查铜线、磁极、柔轮齿、轴承和贯穿孔。
4. 单个世界初始资产遵守现有 15 MiB 预算。记录实际 GLB 大小、三角形、draw calls 和目标浏览器观察值，不能承诺未经测试的帧率。

### 运行逻辑与浏览器

1. 有意义的单元测试覆盖相位保留、传动比、负转速、步进、抱闸、实际转速、重置、旧 schema 兼容、无效引用及销毁订阅。
2. 桌面与手机实际浏览器逐项操作第 7 节控件，组合验证爆炸＋剖视＋单独观察、抱闸＋全局暂停、项目切换及重新进入。
3. 截图检查装配、剖视、展开和移动端；镜头能容纳当前模型，控件可读、无横向溢出、控制台无新增错误。
4. 导出后关闭对编辑服务和外网的依赖，实际操作独立播放器中的机构面板和全局控制，验证与网页一致。
5. 执行 `npm test`、`npm run check`、`npm run build`、`npm run test:browser`、`npm run test:showcases`、`npm run format:check`、`npm audit`；记录实际执行结果，未执行或环境阻塞分别说明。

交付包括模型生成源码与配方、优化 GLB、来源与几何验证清单、共享机构控件、必要的 schema／runtime 扩展、自动验证及人工视觉证据。当前文档只完成设计，尚未开始产品实现，也没有本轮测试通过声明。
