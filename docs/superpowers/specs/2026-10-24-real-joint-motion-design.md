# 真实关节模型：几何约束运动与等效制动设计

状态：用户于 2026-10-24 明确批准按本设计实施并在 UE5 验证。方案 A；设计批准不代表任何工程参数经过实测或人工确认。

## 目标与已确定的方向

以用户提供的 `1700_17关节模组_A1_20261023.STEP` 作为 UE5 关节设计的默认模型。保留真实尺寸、装配位置、零件边界和原始文件；让轴承公转／自转、谐波啮合和抱闸过渡具有可解释、可测试的机械关系。运动在 UE5 中实际运行并检查，网页和独立播放器继续使用相同参数与语义。

用户选择的是“几何约束运动＋等效制动动力学”，不是载荷标定、寿命计算或完整弹性接触仿真。不可把默认 H-100 的尺寸、200/202 齿数、交叉滚子结构或制动参数直接套到真实模型。

## 真实模型接入与零件绑定

1. 将真实模型作为本地 UE 工程默认入口；旧示例保留为参考场景。固定项目来源与源哈希，重新启动仍打开真实模型。
2. 全程以米、Y-up、弧度的 SceneSpec 为序列化事实源。原 CAD Z-up 到场景 Y-up 只作一次明确的刚体变换；再由已有适配器转为 UE 厘米／Z-up。零件不作非均匀缩放，不再压扁滚珠。
3. 按最终 GLB 的实际路径产生零件 ID 和绑定表，保留原装配路径、实体索引与来源。重名、空名不能合并为同一零件；多材质零件可以有多个绘制子网格，但共同从属于同一机械刚体。
4. 为输入、输出、固定壳体、各轴承、衔铁分别记录轴线、支点、所属刚体。通过变换父组重定位支点并保持装配位置；不能仅旋转单个网格的原点。
5. 未识别的实体保持静止并显示“待绑定”。外观原色与运动分组标色可切换；标色不覆盖原资产。检查隔离／剖视时不自动改变机械归属。
6. 绑定与参数通过经过验证的原子 SceneCommands 写入当前项目；异步识别或重建受项目身份和代次约束。运行中的角度、速度、制动计时等不写回 SceneSpec。

## 轴承运动

### 圆形滚珠轴承

- 使用真实实体拟合内外滚道、节圆、球径和中心；没有保持架实体时，计算保持架相位但不冒充 CAD 中已有保持架。
- 计算滚动体中心随保持架公转，以及滚珠相对于公转坐标系的自转；再合成世界旋转。不能直接拿振动诊断中的 BSF 当世界自转速度。
- 例如径向接触、内圈转动外圈固定时：令节圆半径为 R，球半径为 r，滚道接触半径为 Ri=R-r、Ro=R+r。无滑动条件给出 `ωc=(ωi*Ri+ωo*Ro)/(2R)`；自转相对于保持架为 `Ωrel=(ωo-ωi)*Ri*Ro/(2Rr)`，世界旋转还必须包含公转坐标系旋转。一般接触角从实际接触几何计算，不套用这个径向特例。
- 接触点速度残差应接近零；保持架可以慢于内圈，滚珠不能焊死在内圈或外圈上。
- 观察滚动时可开启独立的表面标记层，默认真实外观；没有标记的光滑球体不能仅凭外观证明自转发生。

### 输出轴承与柔性轴承

- 按真实模型识别球／滚子结构；不得因旧示例使用交叉滚子，就将真实轴承改成该结构。
- 若实际是交叉滚子，分别计算两种接触方向的滚动轴和公转；用局部接触残差检验，不强套球轴承自转公式。
- 柔性波发生器轴承分开处理椭圆形状的旋转与材料点沿套圈运动。内圈／凸轮随输入，外圈形变跟随波峰，但外圈材料不应整体焊在输入上。
- 对非圆滚道，用弧长参数和移动接触点速度求中心输运及自转；保持架间距按弧长检查。若简化模型无法同时满足多个接触的无滑动条件，显示并记录滑移残差，不能谎称精确纯滚动。

## 谐波啮合

- 首先检查真实实体是否包含齿形、柔轮、刚轮和波发生器，拟合主轴并数齿；没有可靠证据时齿数保持未确定，不沿用旧模型的 200/202。
- 固定刚轮这一连接方式使用 `ωf=-(Zc-Zf)/Zf*ωw`。只有本次绑定确认刚轮固定时才启用这一约束。
- 两个啮合区随椭圆长轴转动，短轴方向逐渐脱开；关注有限宽度的啮合区，不把两处接触点当作全部受力。
- 从真实齿形检查齿顶／齿根相位、啮入／啮出间隙和贯穿。必要的柔轮变形必须同时考虑径向与切向位移，避免仅靠径向波形造成虚假齿距变化。
- 保留原 CAD 资产；可变形网格作为有来源的派生资产，绑定其真实局部坐标及形变区域，杯底和输出连接区不能被整杯椭圆化。
- 若真实 CAD 没有详细齿形或无法支持可信形变，则真实几何保持不变；在独立、明确标注的“原理层”展示啮合关系。原理层参数仍未确认，不宣称补全了厂商内部设计。
- 对全部输入相位、正反转与主要装配状态做密集几何采样，报告最大穿透／间隙和采样范围。不再把所有齿轮相交简单列成允许接触后就算啮合正确；不把离散采样称为连续接触证明。

## 抱闸：连续过渡而非瞬时锁停

所选结构为永磁吸合、通电释放。先核对实际衔铁、固定极面和线圈；若 CAD 与此不符则保留未绑定，不用旧示例的名称强行指认。

状态过程：

`已释放 → 断电响应延迟 → 衔铁闭合／力矩建立 → 滑摩减速 → 静止保持`

`静止保持 → 通电释放延迟 → 衔铁回退／力矩消退 → 已释放`

- 轴系使用等效转动惯量，满足 `J*ωdot = Tdrive - Tbrake - Tdrag`。本轮默认无外部负载扰动，不新增传动弹性自由度。
- 轴角由实际角速度积分。抱闸接触时制动力矩总是反对相对运动，摩擦耗散不能为负；计算停车角和耗散能量，不能在切换电源时直接把速度归零。
- 过零时处理静摩擦保持，不能因离散步长产生反向弹转。保持只在所受力矩小于配置的保持能力时成立，不能无条件无限锁住轴。
- 驱动器在未完全释放时禁止启动；断电请求撤去驱动请求。重新上电释放不自动恢复播放，需再次启动。
- 普通停止采用有转矩／加速度限制的驱动减速，与断电抱闸区分。反转先减速过零再反向加速，不瞬间跳变角速度。
- 衔铁沿真实轴向小行程移动；空气隙缩小和摩擦接触过程可观察。无实测气隙、响应时间、惯量、力矩和阻尼时，用有明显“演示假设”标记的可调预设，绝不标为实测或工程确认。
- 参数严格校验有限性、正值、单位、范围和零时间边界。预设的具体演示数值由实施者选择并记录来源，不移植某款供应商额定值作为本型号性能。

## 时间、操作与实现一致性

- 默认按真实经过时间推进仿真；提供明确显示的慢放倍率，以观察毫秒级抱闸过程。慢放改变仿真时钟，不更改物理参数，读数采用仿真时间单位。
- 暂停／窗口挂起冻结仿真时钟与制动计时，恢复不补算后台时间。暂停不是制动事件；显示设定速度、仿真速度和暂停状态的区别。
- JS 与 UE C++ 从同一份序列化配置读取参数和绑定；使用相同状态机与符号约定，并以共享输入场景作数值对照。可选择解析分段积分或事件感知子步进，但必须通过低帧率及时间分割一致性检查，不能丢弃有效经过时间。
- 释放网格实例、动态材质及控制状态；切换模型、导入取消或异步工作过期后不得影响新的模型。

## 验收条件

1. 真实 STEP 原文件哈希不变，最终 GLB 自包含、层级与单位正确；默认 UE 工程重启后仍加载真实模型。保留校验警告与来源。
2. 零件绑定表覆盖将被驱动的实体；未知件不运动。固定壳体不跟转，刚体在运动中不缩放或变形。
3. 圆形轴承接触速度残差、保持架相位和自转方向通过数值测试；非圆轴承报告接触残差，UE 中用标记／相位读回及分时画面验证实际网格运动。
4. 核验真实齿数依据、传动符号、两个啮合区及完整周期的密集几何采样；CAD 缺省处与原理层明确区分。
5. 抱闸正反转、不同初始速度、响应延迟、力矩斜坡、停车时间／角度、能量耗散和释放互锁均有确定性检查。能量及摩擦符号正确，无数值反转、角度跳跃或误自动启动。
6. 5／10／20／60 FPS、不同时间分割、暂停与慢放下结果一致至明确容差；容差及数值积分方案在实施计划中确定并随测试记录。
7. UE C++ 编译、原生自动化、实际渲染多相位／制动过程捕获与读回通过。导入成功或截图存在不等于机械正确；不得仅检查动画权重。
8. 运行适当的完整单元／集成、类型、构建、格式及浏览器回归；报告实际执行项。没有实物／标定数据时不声明真实制动距离、承载、寿命、温升或认证通过。
