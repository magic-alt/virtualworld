# Blender 案例与验收

本次案例沿用 React → SceneSpec → Three.js 的模块架构。默认项目为 `demo-harmonic-joint`。J-01、星屿来信、沙漠绿洲、宁静森林已从产品目录与接口移除；小王子三章完整保留。测试专用几何与用户案例隔离。用 `?project=<ID>` 可指定打开的案例。

## 小王子三章

`worlds/little-prince/campaign.json` 定义有序章节和解锁依赖；每章在 `chapters/` 下保留 `scene.json`、`story.json`、`assets.json`。依据[法文原作](https://www.ebooksgratuits.com/html/st_exupery_le_petit_prince.html)第二、五至九、二十至二十一章，用原创中文转述改编。

| 章节 | 可探索内容 | 玩家 |
| --- | --- | --- |
| 沙漠相遇 | 故障飞机、小旅人、画羊与箱子的交流 | 飞行员 |
| B-612 | 玫瑰与玻璃罩、两座活火山与一座休眠火山、幼苗与落日 | 小王子 |
| 地球 | 玫瑰园、麦田与狐狸、建立关系后再看玫瑰 | 小王子 |

这三个片段并非全书复刻。美术采用原创、可辨认的人物形状与 PBR 材质；不复制现代译文或商业插画。人物内含 Idle/Walk/Interact 骨骼动画，NPC 与狐狸有独立动画实例。静态地形使用加载后世界坐标三角网格碰撞；B-612 明确声明中心与半径 6 m，角色重力、胶囊朝向与相机随表面法线调整。

章节进度由 `SaveSystem` 按剧情指纹检查和重放可达标记；`CampaignProgress` 从通过验证的章节完成状态推导解锁。剧情变化会使旧进度失效。浏览器禁止本地存储时，可在当前会话继续；关闭页面后的恢复需要可用的本地存储。

## 谐波关节

`worlds/demo-harmonic-joint/` 是原创教学设计，不是某厂商 CAD。固定刚轮 202 齿、杯形柔轮 200 齿；输入为波发生器，柔轮和输出法兰同步负向减速。依据[谐波传动工作原理](https://harmonicdrive.de/en/technology/harmonic-drive-gears)，本例输出角度为 `−input/100`。双 morph 仅演示相对柔轮的双波变形，不能当作接触或应力求解。

名义尺寸为底座 Ø215 mm、壳体 Ø180 mm、总高 165 mm、连续通孔 Ø20 mm，电机径向气隙 0.5 mm。包含定子/线圈、转子/磁钢、中空输入轴与独立支承、波发生器、柔轮/刚轮、交叉滚子输出支承、法兰、编码器和紧固件。运动根节点独立，固定件不得置于运动根节点下；生成的关节参数 `confirmed:false`。

配方检查尺寸、孔位、气隙、同轴基准和名义三角表面交叠；已知接触以明确部件对列举。它不能证明实体完全包含、连续运动间隙、公差累计、生产装配、强度、额定扭矩、疲劳或热性能。齿廓和滚道是展示近似，未执行 FEA 或实物验收。详细结构、接触和构建流程见 [H-100 配方说明](../generators/blender/harmonic/README.md)。

## 构建、运行与导出

`npm run demos:build` 调用本机 Blender 的固定 Python 配方，失败退出不会发布新场景。GLB 保留骨骼、动画、morph 和嵌入纹理，完成后运行 Khronos Validator，记录工具版本、SHA-256、体积和几何检查。运行资产提交到 `assets/optimized/showcase/`；`.blend` 和审查 PNG 留在本地。

章节发现、保存和导出均检查 manifest 的场景 ID、campaign ID 和章节序号。整章合集导出按内容哈希去重资源，播放器与 JSON 使用相对路径，无需 API、模型密钥或外部 CDN。解压后通过 HTTP 打开 `index.html`，支持子目录。

## 实际验收

验收命令为 `npm test`、`npm run check`、`npm run build`、`npm run demos:validate`、`npm run test:browser` 和 `npm run test:showcases`。新浏览器脚本使用本机 Edge、1280×720、DPR 1、GTX 1660 SUPER；每个场景预热后采样 10 秒。目标为平均 ≥55 FPS、P95 ≤25 ms、可见三角形 <750k、draw call <150，每章资产 <15 MiB。结果记录在 `output/playwright/showcases/`，该目录不入 Git。

浏览器检查区分真实键盘行走/跳跃与故事测试的定位夹具，后者用于稳定覆盖全部依赖链，不声称人工走完整条路线。离线验收停止编辑 API，阻止外部请求后加载整包，检查章节切换、恢复与重置。手机只检查布局，不声明移动端 GPU 性能。

## 案例清理验收

按用户明确指定，移除 J-01、星屿来信、金色岩石与失落星门组成的沙漠绿洲、蓝色晶石与古树环绕的宁静森林。其 ID `demo-industrial`、`demo-world`、`generated-desert`、`generated-forest` 不再列出，读取返回 404，保存和导出被拒绝；已有同 ID 磁盘文件不会使案例重新出现。保留 H-100 和小王子三章，其场景与模型文件未修改。用户自建项目仍可保存和打开。

新建项目从空白 SceneSpec 开始。旧几何的回归测试数据移至 `tests/fixtures/`，使用独立 `test-*` ID；浏览器检查只向临时 API 注入夹具，正常启动不会加载它们。2026-10-18 清理后实际执行：26 个文件、101 项测试，TypeScript/生产构建/格式检查通过；26 项 Edge 浏览器检查通过、0 错误，其中直接检查正常目录仅四个项目及 H-100/小王子快捷入口。4 个保留场景资产校验通过，7 个 GLB 仍为 0 错误、0 警告。
