# UE5 本机鼠标与模型验证记录

本轮基于已合并 PR #16 的 `158b44b`，在 Windows、UE 5.8.4（58902052）、Node.js 24.22.1、MSVC 14.44、Windows SDK 10.0.26100.0 上执行。检测到 RTX 5060；后续检查均使用 1280×720 窗口。

## 改动

- 可见光标与可点击 HUD 下，使用鼠标位置差跟踪手势。关节视口支持左/右拖动旋转、中键平移和滚轮缩放；面板内滚轮只滚动面板，面板起始按键不会在移入视口后启动拖动。松键、失去位置和失焦会结束手势。小王子保留左键交互与右键旋转。
- 平移按正交视平面和水平 FOV / 视口宽度映射，避免宽屏比例错误。Home 仍只复位视角，不改变机构或剧情状态。
- 构建设置跟随实际 UE 默认值，修复 UE 5.8 共享 Editor 构建冲突；测试上下文采用等价显式标志，兼容已移除的枚举成员。
- 仅对声明网格碰撞的模型启用复杂碰撞，修复装饰模型被错误要求 CPU 碰撞数据的导入失败。
- 为 H-100 金属提供运行时临时 HDR 环境反射，改善空 Entry 地图捕获为黑色的画面。第一版反射过亮，经反馈降至其四分之一，保留原金属材质与明暗层次；消除方向光优先级冲突。
- 启动器使用窗口模式。GLB、SceneSpec、机构参数均未改动，没有重新生成模型或调用付费生成服务。
