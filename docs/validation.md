## 审查与修复证据

独立只读审查发现并验证了 4 项重要问题，均修复并复查：

1. Spark 延迟初始化在销毁后仍分配资源：使用可延迟的库加载夹具观察失败，再加入销毁保护；测试通过。
2. CLI 校验新上传文件时仍寻找旧路径：使用真实库布局重现 ENOENT，再统一上传解析器及旧目录回退；测试通过。
3. 生成缓存只校验场景、不校验资产：删除/损坏 GLB 重现，再校验文件与哈希并从源重建；测试通过。
4. 密钥轮换绕过任务缓存导致重复计费：本地 HTTP 任务创建计数从 1 变 2 重现，再让内容/端点/模型决定缓存并优先恢复原始文件；计数保持 1。

最后一次独立复查未发现上述恢复/缓存修改中仍有 Important 问题。该结论限于审查代码及执行过的受控测试。
