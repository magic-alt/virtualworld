- Unreal 纠正源模型 +Z 到原生控制器方向的视觉朝向；保留脚底偏移。
- Unreal 允许显式直达导出的章节，同时保留后续菜单前置条件；不删除有效章节存档。
- Unreal 有地形碰撞时拒绝无支撑的行走步进，避免走出地球地形后悬空继续移动。

Unreal 的便携 SHA-256 实现另外使用 C++17 严格告警编译，并与十组长度/填充边界
数据比较通过。这只覆盖该独立哈希实现，**不等于 Unreal 模块编译通过**。
