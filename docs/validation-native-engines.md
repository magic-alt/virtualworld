## 未通过的广泛浏览器回归

本次不能宣称完整 `npm run test:browser` 通过：

1. 两次全流程在初始 H-100 编辑器的「切换项目」或「切换到故事世界」点击上达到
   30 秒超时。随后分别在干净基线和当前构建运行完全相同的初始操作，均通过且
   无页面错误。故这两次超时仍属于**原因未确定的间歇性失败**，不能断言是此次
   改动造成，也不能断言是基线缺陷。
2. 单独执行 `world-experience-check.mjs` 时，桌面创建、探索、暂停、画质、AI 提案、
   撤销/保存及异步项目隔离检查通过，但移动端摇杆的固定 350 ms 位移断言失败。
   在未修改的同一基线、相同浏览器与场景生成流程中，该断言同样失败：位移为
   **0.1270588 m**，小于原断言的 **0.3 m**。测试等待和阈值均未放宽。

软件渲染时序是可能原因，但上述证据尚未证明根因。合并/发布前仍需在目标浏览器
和实际 GPU 上重跑完整检查。未重新运行的长期稳定性、全部案例、真实移动 GPU
和原生性能检查不计为通过。

## 源码复核中修正的问题

- 原生入口在保存后重新读取修订号，防止继续打开缓存中的旧构建。
- 原生入口和下载跟随正在显示的章节，URL 保留该章节身份。
- 移除 iframe load 事件等同于原生就绪的错误假设。
- Unity 构建使用全新目录，避免改一个 exe 名称后覆盖旧构建的同目录文件。
- Unity 中文字体绑定进入目录资产和新场景，批量重建不再丢失；保留字体许可证。
- Unreal 纠正源模型 +Z 到原生控制器方向的视觉朝向；保留脚底偏移。
- Unreal 允许显式直达导出的章节，同时保留后续菜单前置条件；不删除有效章节存档。
- Unreal 有地形碰撞时拒绝无支撑的行走步进，避免走出地球地形后悬空继续移动。

Unreal 的便携 SHA-256 实现另外使用 C++17 严格告警编译，并与十组长度/填充边界
数据比较通过。这只覆盖该独立哈希实现，**不等于 Unreal 模块编译通过**。
